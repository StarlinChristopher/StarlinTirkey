# Complete AWS DevOps Project

Multi-environment AWS DevOps project for **development**, **staging**, and **production**.

This project includes Infrastructure as Code, Kubernetes manifests, and an automated CI/CD pipeline based on the architecture in `IMG_8146.jpeg`.

## Tech Stack

- **Cloud:** AWS — VPC, EKS, RDS, ECR, and ALB
- **Infrastructure as Code:** Terraform
- **CI/CD:** GitHub Actions
- **Containers:** Docker and Kubernetes
- **Application:** Java 17 microservice
